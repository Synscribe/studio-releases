# Mole Studio downloads

Mole Studio is a video studio for Claude Code and Codex, for Macs with Apple silicon. It is in beta.

Get it from **[agentmole.io/studio](https://agentmole.io/studio)**. That page has the current version, what you need, and how to start.

This repository holds only the release files (the DMG, the update zip and the Chrome extension zip). The app downloads its updates from here. The source code is not public.
